# Changelog

## Unreleased

- Accepted ADR 0012: spqx (Apache, MLX) and kokorox (GPL, ONNX) stay separate engines unified by contract, not code merge — spqx's binary worker protocol made engine-agnostic (kokorox worker: `kokorox-7ngw`; foxline backend: `fxl-8bht`), kokorox-openai as the reference HTTP contract (spqx convergence: `spqx-wr4b`), engine-neutral Persona voice resolution (`fxl-00hv`), GPL confined to the kokorox worker process, and a tracked GPL exit for kokorox (`kokorox-8j45`). No runtime behavior changes yet.

- Specified (not yet shipped) work-directory pairing in ADR 0011: `foxline pair` must grant selected-directory past chats and voice sessions with Oqto-compatible durable Session IDs and Runner-backed history, while `oqto-sandbox` confines the agent process separately from phone authentication. The current Mac Oqto runner provides read-only history but not live chat attachment; server enrollment and physical phone voice remain open.
- Replaced the neutral Tauri app's placeholder desktop/iPhone icons and byteowlz browser favicon with the tracked Foxline square logo. `just neutral-app-icons` regenerates the full icon set; iOS requires a rebuild because the artwork is compiled into `Assets.car`. The rebuilt app was signed in an Aqua GUI session, verified, installed and launched on the paired iPhone; this does not prove a paired or audible conversation.
- Added a Tauri-native Rust WSS bridge for iPhone and desktop, with CA-chain/hostname/expiry validation and an exact leaf SHA-256 pin supplied by a trusted server-identity channel. The Client Core now accepts a socket factory; no local-CA installation or DNS-01 certificate is needed for a pinned tailnet endpoint. Added `foxline identity-qr` and in-app camera scanning to transfer only public trust material, not a credential. Verified a loopback TLS fixture, a live tailnet WebSocket handshake, QR decoding and iOS cross-compilation. This is **transport only**: QR enrollment, scoped/revocable device credentials, server-side workspace authorization, and physical iPhone audio verification remain open (ADR 0010).
- Added gateway speech endpointing: STT segment finals now wait for `[turn].silence_timeout_ms` (default 650 ms), merge across brief pauses and remain provisional until commit. Renewed speech suspends the deadline; typed submissions remain immediate. **Migration:** the previously unused setting now adds delay after backend VAD/decoder finalization; `0` restores immediate-final behavior. Fake-clock mapper/pipeline regression tests pass; physical-phone tuning remains pending (`fxl-rw9m.1`).
- Fenced spqx/Qwen TTS adapter output by cancellation generation, dropping obsolete queued audio/completion/errors even after worker completion or late producer enqueue. Cancellation invalidates state before worker I/O; shutdown clears active requests. Brain-output fencing and gateway lifecycle/authorization remain open (`fxl-xp29`).

- Corrected iOS signing to the verified byteowlz Team ID `K8RV7BFSRS` (not the development certificate's display-name suffix). Verified signed Tauri device build/export, signature validation, installation and launch on the paired iPhone 15 Pro. Documented separate background-session keychain signing failures and the working Terminal build path. Native connectivity/audio validation remains pending (`fxl-pras`).

Root `dev/build/start/preview/typecheck/test` now select Foxline. Both canonical development and built-server proxies now default to the standard gateway port `8780`, rather than spike port `8783`; `FOXLINE_GATEWAY_URL` still overrides it.
- Refined the canonical conversation experience: non-overlapping desktop transcript rail, phone/tablet conversation view with persistent voice controls, multiline/IME-safe composer, draft retention, return-to-latest control, coherent permission/text-only/error states, and settings that do not reconnect for appearance-only changes. Hidden mobile presence rendering pauses without interrupting audio. KITT, Relay, the three Phosphor modes and the shared scheme/radius mechanism are preserved.
